### osago-aggregator

ли ему своё хранилище данных?
- Да, как минимум для хранения каких-либо промежуточных результатов

Какой API он предоставляет core-app?
- самый основной - создание заявки от клиента
- промежуточные данные о предложениях по страховым

Определите средство интеграции между сервисами core-app и osago-aggregator.
- REST - для создания заявки
- ассинхронное взаимодействие через Kafka

В зависимости от выбранных средств интеграции подумайте, требуется ли где-то применение паттернов отказоустойчивости
- Rate Limiting - может понадобиться при увеличении количества пользователей
- Timeout - для ограничения запросов к страховой
- Retry - если запрос к страховой не прошел\ произошла ошибка
